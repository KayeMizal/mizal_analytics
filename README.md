# Mizal Analytics

This project is a Streamlit app that predicts whether an employee is suitable for high-priority tasks.

## Files

- app.py - main Streamlit application
- structured_data (1).csv - dataset used by the app
- Mizal_Analytics_Model_Development.ipynb - notebook for model development
- requirements.txt - needed Python packages

## How to Run

pip install -r requirements.txt
streamlit run app.py
